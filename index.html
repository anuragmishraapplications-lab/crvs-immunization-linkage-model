What could linking birth registries to immunization programmes deliver?

Where registration is high but immunization lags, the state already knows these children exist. The registry can be used as a find-list for the ones missing vaccines. This model sizes that opportunity conservatively and prices it against published evidence.

Define the opportunity

The registry can only reach children recorded in it, so this threshold sets how much of the case rests on registry data actually existing.

Registration minus immunization. Below this the headroom is too small to justify the intervention.

The scenario arithmetic

For each country the source sheet gives two marginal rates: birth registration and DPT3 immunization. It does not give the join between them. Without that cross-tabulation a point estimate is not available, so the model brackets the answer.

Ceiling (optimistic) = Birth registration − Immunization CLASS C
Assumes every unvaccinated child is registered, so the registry can find all of them and coverage climbs to the registration rate.
Floor (conservative) = (Birth registration − Immunization) − (100 − Birth registration) CLASS C
Assumes every unregistered child is also unvaccinated, so that whole slice is invisible to the registry and is stripped out of the headroom.

Worked through: Gabon registers 89.6% of births and immunizes 61%. The gap is 29 points, the unregistered share 10, so even in the worst case linkage is worth about 19 points. Honduras registers 97% and immunizes 75% — a 22-point gap against only 3 points unregistered, so the floor is 19 again, this time capturing nearly the whole gap. That convergence is the point: the higher registration goes, the less the conservative assumption costs you.

Turning coverage points into money

Two published parameters multiplied. A benefit–cost ratio for childhood immunization in low- and middle-income countries, and a cost per fully immunized child that converts the ratio into an absolute figure.

Children reached = Floor (pp) ÷ 100 × annual birth cohort
Gross benefit = Children reached × benefit per child
Net benefit = Gross benefit − (Children reached × delivery cost)

Three assumptions worth stating out loud

Average cost is not marginal cost CLASS C

Published ROI ratios are programme averages that include easy-to-reach children. This intervention targets the children the system has been missing, who cost substantially more to find. Benefit per child is broadly unchanged — disease burden averted is a property of the child, not of how hard they were to reach — but cost rises, which is why the model nets out a marginal delivery cost rather than applying the headline ratio unadjusted. On the defaults this pulls the effective return to roughly 7× rather than the published 20×.

DPT3 stands in for the full schedule CLASS C

Benefit figures assume a child the system reaches completes the whole infant schedule, not only the DPT doses. DPT3 is the standard proxy for a child the system has genuinely reached, which makes this defensible, but a strict floor counting only diphtheria, tetanus and pertussis burden would be materially smaller.

The registry only helps if identification is the constraint CLASS C

Every number here assumes a child is unvaccinated because the programme could not find them. Where the real barrier is conflict, supply failure or economic collapse, the registry can locate the child and change nothing. That is why several high-gap countries are set aside by default rather than counted, and why that judgement is a toggle rather than a hidden filter.
